# Data from 'Switching Functional DNA-Binding Modes by Tuning Protein Order-Disorder Equilibria' 

bioRxiv version --> https://www.biorxiv.org/content/10.64898/2026.08.11.744313v1 

Github_Nhp6A_Data.xlsx --> Excel file contains all the data used to plot the graphs (except Figure 5)

CoopTmScenarios.m --> A MATLAB script that simulates the different Tm-DHm scenarios shown in Figure 8

OrthologStructures.zip --> The PDB files of the 10 Nhp6A orthologs spanning the fungal taxa

Hashi_PymolFig_N.pse, Hashi_PymolFig_Nstar.pse --> Structural ensembles of N and N* from the Hashi workflow (https://github.com/AthiNaganathan/Hashi) 

WSME model codes --> https://github.com/AthiNaganathan/WSMEmodel
